Confirmed `superset/mcp_service/common/time_range_validation.py::validate_time_range()` intentionally defers explicit reversed ranges downstream by design (its own docstring), and found an exact fix-shape precedent already in-repo (`update_dashboard.py`, `apply_dashboard_filters.py` both catch `ValueError` function-wide and return a typed error).
