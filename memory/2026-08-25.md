**Verified false from source** (corrects the 08-24 memory framing, which loosely called it a "Spark/Trino typed-path gap"):
- `BaseTemplateProcessor.process_template` (`jinja_context.py:986`) does the structured `TemplateSyntaxError` → `SupersetSyntaxErrorException` conversion (`:1034`).
- `Presto`→`Hive`→`Spark`, and `Trino` processors (`:1129–1216`) ALL inherit it unchanged — **none override `process_template`**. There is no separate "direct-rendering" path. Only `NoOpTemplateProcessor` overrides (returns str, no error).
