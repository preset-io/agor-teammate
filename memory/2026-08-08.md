### Picked: `MANAGER-PYTHON-40C` — `WorkspaceUpgradeManager.get_all_target_ids_for_upgrade()` wrong status-filter sentinel

**Root cause** (verified by reading source, not guessed): `_get_upgrade_for_update(upgrade_id, expected_states=None)` treats an *explicitly passed* `None` identically to "caller omitted the kwarg" — both fall back to `[WorkspaceUpgradeStatus.STAGED]` (`preset/managers/workspace_upgrade.py`). `get_all_target_ids_for_upgrade()` calls it with `expected_states=None` intending existence-check-only (per its own docstring: "Raises WorkspaceUpgradeNotFoundException if upgrade doesn't exist" — no status restriction stated), so any GET to the target-ids endpoint for an upgrade that exists but isn't STAGED (SUCCESS/RUNNING/FAILED — the normal state once an upgrade has progressed) incorrectly raises `WorkspaceUpgradeInvalidStatusException`. The file already has the correct pattern for "existence-check-only" elsewhere in the same class — `get_upgrade_stats()` passes `expected_states=[]` (empty list is falsy, short-circuits the `elif expected_states and ...` guard). Confirmed via Sentry sample event: upgrade id 3082493, status SUCCESS, expected `[STAGED]` — an already-completed upgrade can never fetch its own target ids via this endpoint.

**Fix**: one-line, `expected_states=None` → `expected_states=[]` at the `get_all_target_ids_for_upgrade` call site, mirroring `get_upgrade_stats`'s exact existing pattern. `_get_upgrade_for_update`'s own default-substitution logic untouched (other callers that omit the kwarg still get the STAGED default). **Test**: no prior coverage existed for this method at all (likely why it shipped) — added `test_get_all_target_ids_for_non_staged_upgrade` (SUCCESS-status upgrade, asserts target ids returned instead of raising) and `test_get_all_target_ids_for_upgrade_not_found` (behavior-unchanged check) to `tests/preset/managers/test_upgrade_manager.py`. Fail-before/pass-after verified on real Postgres: pre-fix raises `WorkspaceUpgradeInvalidStatusException` exactly as in Sentry; post-fix passes. Full `WorkspaceUpgradeManagerTests` class: 129/129 passed (127 existing + 2 new), no regressions. `ruff check` + `ruff format --check` (repo-pinned 0.6.5): clean.
