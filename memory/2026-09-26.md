**Third candidate, picked**: `superset/daos/dashboard.py::DashboardDAO.set_dash_metadata`, ~line 416:
```python
default_filters_data = json.loads(data.get("default_filters", "{}"))
```
Inside the `if (positions := data.get("positions")) is not None:` block (an empty `{}` satisfies this). No try/except around this specific call — a non-empty, non-JSON `default_filters` string raises a raw `simplejson.JSONDecodeError` (`ValueError` subclass, not a `SupersetException`).

**Reachability, verified independently**: `superset/dashboards/schemas.py::DashboardJSONMetadataSchema.default_filters = fields.Str()` (~217) only checks it's a string, never validates JSON content. `validate_json_metadata()` (~122) validates the outer `json_metadata` string against that schema but doesn't inspect `default_filters`' content — so `PUT /api/v1/dashboard/<pk>` with `json_metadata: '{"default_filters": "not-json"}'` passes validation cleanly. `commands/dashboard/update.py` (~131) and `create.py` (~67) both call `DashboardDAO.set_dash_metadata(dashboard, data=json.loads(json_metadata))` unconditionally when `json_metadata` is present. Both commands are wrapped in `@transaction(on_error=partial(on_error, reraise=Dashboard{Update,Create}FailedError))`, but `on_error()` (`superset/utils/decorators.py:221`) defaults `catches=(SQLAlchemyError,)` and neither call site overrides it — `JSONDecodeError` isn't a `SQLAlchemyError`, so `on_error` hits its `else: raise ex` branch and the raw exception passes through unconverted. `dashboards/api.py`'s `put()`/`post()` only catch specific Superset exceptions, no catch-all — raw exception reaches FAB's default handler as an opaque 500 where a 422 is clearly intended.

**Sibling precedent, same file/class**: `DashboardDAO.update_native_filters_config`, ~line 579-582, already does `except (json.JSONDecodeError, TypeError): _parsed = {}` for the identical `json.loads(dashboard.json_metadata or "{}")` shape. `set_dash_metadata`'s `default_filters_data` line never got the same treatment. Mirroring that exact soft-fallback idiom (not raising) is the minimal, non-behavior-changing fix.
