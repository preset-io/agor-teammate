### Root cause (verified against `preset-io/manager` master via `gh api`, not guessed)
`preset/controllers/api/schemas.py::extra_validator` (the marshmallow validator wired to `DatabaseSchema.extra` and `DatabaseTestConnectionSchema.extra`, backing the workspace database create/update/test-connection endpoints) does `extra_ = json.loads(value)` then unconditionally `extra_.get("metadata_params", {})`. `json.loads` on a JSON-encoded non-object string (e.g. `"123"`, `"true"`, `"[1,2,3]"`, `"null"`) succeeds and returns an `int`/`bool`/`list`/`None`, not a `dict` — `.get()` then raises exactly the captured `AttributeError`. No `isinstance` guard exists between the JSON-decode success and the `.get()` call. Confirmed both schema call sites via `gh api search/code`.
